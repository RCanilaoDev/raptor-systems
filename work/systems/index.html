Standard // How Work Moves

A finding should earn its place in production.

Raptor separates verification, priority, sequencing, and implementation so tool output does not become unexamined work.

01Verify the condition.

Inspect, reproduce, corroborate, and document the evidence before recommending action.

02Determine importance.

Consider technical severity, search impact, business impact, and verification confidence.

03Sequence responsibly.

Map effort, dependencies, implementation risk, and the logical order of operations.

04Verify the result.

Quality check the implementation, deploy carefully, and confirm the intended condition changed.
