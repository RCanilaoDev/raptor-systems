Control Framework // Work With State

Every project needs a visible current condition.

A website should not simply be described as in progress. Its current state, owner, blockers, required evidence, and next transition should be visible.

This makes handoffs clearer, exposes stalled work, and gives quality checks a defined place in the production sequence instead of treating review as a last-minute event.
