HQCP // HUMAN REVIEW REQUIRED DETECTION ≠ DIAGNOSIS
Audit Definition

The whole SEO system, not one score.

A website can pass one crawler test and still have serious organic search problems. Raptor investigates the connected system behind discovery, indexing, relevance, performance, user experience, authority, and measurement.

QUESTION // 01

Can search engines find it?

We examine crawl paths, robots directives, internal links, XML sitemaps, access conditions, orphan risk, and other barriers to discovery.

QUESTION // 02

Are the right pages indexed?

We inspect canonical signals, redirects, duplication, meta robots, index status, and whether search engines are storing the pages the business actually wants found.

QUESTION // 03

Does the site deserve to perform?

We connect technical health with content quality, intent alignment, structured data, authority, speed, usability, and measurement instead of treating each one as a separate checklist.

Audit Scope // 8 Systems

What Raptor investigates.

Every category is examined in context. The purpose isn't to maximize the number of issues found. It's to identify conditions that can materially affect search performance or the business value of organic traffic.

01

Discovery & Crawlability

Robots.txt, XML sitemaps, crawl paths, status codes, redirects, internal linking, pagination, faceted navigation, crawl depth, orphan risk, and crawl waste.

02

Indexation & Canonicalization

Index state, canonical tags, redirect chains, duplicate URLs, parameter behavior, meta robots, alternate versions, and signals that can split or suppress indexing.

03

Performance & Core Web Vitals

LCP, INP, CLS, page weight, requests, JavaScript, CSS, images, fonts, apps, caching, CDN behavior, server response, and mobile performance.

04

On-Page Search Architecture

Search intent, titles, meta descriptions, headings, URLs, anchors, image alt text, internal linking, content hierarchy, mobile presentation, and conversion alignment.

05

Content Quality & Relevance

Page purpose, topical coverage, duplication, content gaps, clarity, entity signals, E-E-A-T support, thin pages, cannibalization, and rewrite opportunities.

06

Structured Data & Entity Signals

Schema types, JSON-LD, syntax, entity consistency, relationships, visible-content alignment, rich-result eligibility, and Organization or LocalBusiness signals when appropriate.

07

Authority & Backlink Health

Authority patterns, referring domains, link quality, anchors, suspicious or toxic patterns, lost links, competitor gaps, and whether authority problems deserve action.

08

Measurement & Search Intelligence

Google Search Console, GA4, GTM, conversion tracking, event integrity, search queries, landing pages, business KPIs, and whether reported performance can be trusted.

HQCP // Human Quality Control Protocol

A tool finding isn't automatically a client finding.

Detection is the start of the investigation. Diagnosis requires context, evidence, and human judgment.

Raptor uses crawlers, validators, analytics platforms, search data, browser tools, AI, and other systems to surface evidence. Material findings move through HQCP before they become recommendations.

RAPTOR RULE Detection is not diagnosis.

Automated output can be wrong, duplicated, immaterial, or technically accurate but irrelevant to the business. Raptor verifies before recommending action.

V0
DetectedPotential issue identified by a person, tool, platform, validator, crawler, AI system, or other source.
V1
InspectedHuman review completed to determine whether the finding is plausible and relevant.
V2
ReproducedThe condition is observed directly using an appropriate independent method.
V3
CorroboratedA second independent source supports the finding when the issue is material or uncertain.
V4
VerifiedEvidence, context, impact, and recommended action are documented and ready for client delivery.

Good Fit // Technical SEO

When this audit makes sense.

Organic traffic has declined or stalled. The site has crawl, indexing, or Core Web Vitals concerns. A redesign, migration, platform change, or major launch is planned. SEO tools report many errors but the real priorities are unclear. The site has grown without a consistent technical SEO system. Analytics and search reporting don't fully agree or can't be trusted. An ecommerce store has product, collection, schema, indexation, or performance issues. The team needs a verified roadmap before implementation begins.
